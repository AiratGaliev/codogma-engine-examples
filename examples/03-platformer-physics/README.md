# Platformer Physics

**Runtime:** Phaser 4.2.1 · **Формат:** Codogma Scene Editor + TypeScript.

## Задача

Игровой уровень, собранный из объектов Scene Editor. Код добавляет Arcade Physics к игроку и платформам, управляет движением и прыжком, собирает жетоны и заставляет камеру следовать за персонажем.

## Что изучать в Codogma

- Состав уровня и геометрия платформ задаются в `PlatformerLevel.scene`.
- Arcade Physics, столкновения, клавиатура, overlap и камера следования.
- Форма и расположение объектов остаются редактируемыми; физическое поведение задаётся TypeScript.

## Управление

← / → — движение. Space — прыжок. Соберите три жетона. Клик мышью не требуется. После x=480 камера прокручивается за героем, а HUD остаётся закреплённым на экране.

## Файлы сцены

- `scenes/PlatformerLevel.scene`

## Запуск

Из корня репозитория выполните `npm install --no-audit --no-fund` и `npm run build`, затем откройте проект через локальный HTTP-сервер или в Codogma Engine. Runtime загружается по закреплённому URL Phaser 4.2.1; для первого запуска нужен интернет.

Сцена и TypeScript хранятся отдельно: изменяйте композицию в Scene Editor, а механику — в пользовательском коде. После изменения исходников выполните сборку повторно.

**Важно:** успешная компиляция не заменяет ручную проверку в Codogma. Этот пример должен быть открыт, изменён, сохранён, переоткрыт и запущен в браузере перед тем, как считать соответствующий workflow принятым.
