# Codogma Engine — Examples

Коллекция небольших, но законченных **редакторских проектов** для Codogma Engine и Phaser 4.2.1. Это не каталог изолированных фрагментов API: основной материал каждого примера — редактируемые сцены `.scene`, повторно используемые Prefab, композиция объектов и пользовательский TypeScript-код, который реализует поведение.

## Принципы коллекции

- **Scene-first, а не code-first.** Геометрия уровня, визуальная композиция, тексты, объекты и их расположение по возможности хранятся в сценах Codogma.
- **Небольшая законченная задача.** Каждый проект показывает отдельный редакторский workflow и остаётся достаточно компактным для самостоятельного изучения.
- **Один точный runtime.** В примерах закреплён Phaser 4.2.1; API, чувствительный к версии, проверяется на этой версии.
- **Лицензионно безопасные ресурсы.** Первая подборка использует оригинальные векторные фигуры Phaser и не переносит сторонние изображения, звуки или шрифты.
- **Честная приёмка.** Статическая проверка файлов и TypeScript-компиляция не заменяют запуск проекта в Codogma и проверку браузерного поведения. Статус ручной проверки указан отдельно.

## Начало работы

Требования: Node.js 22.x и npm.

```bash
npm install --no-audit --no-fund
npm run test
npm run build
```

Команда `npm run build` компилирует TypeScript-проекты в локальный `game.js`. Это генерируемые файлы, они исключены из Git.

Каждый проект можно изучать из своего каталога `examples/*`. Для runtime-preview проект использует закреплённый адрес Phaser 4.2.1 из jsDelivr; первое открытие требует доступа к CDN. `index.html` рассчитан на локальный HTTP-сервер — не открывайте его через `file://`, поскольку браузеры ограничивают загрузку скриптов и ресурсов с локальной файловой системы.

## Работа с редактором

1. Откройте нужный каталог примера как проект в Codogma Engine.
2. Откройте `.scene` в Scene Editor и изучите Hierarchy и Inspector.
3. Меняйте размещение, размеры, цвета и текст объектов, затем сохраните сцену.
4. Сверьте изменения со сценой и TypeScript-компиляцией. Для самостоятельного запуска после изменения сцены пересоберите проект.
5. Проверьте игру в браузере. Поведение, которое зависит от конкретного workflow редактора, не считается принятым только на основании успешной компиляции.

## Источники

Для каждого проекта выбраны конкретные официальные ориентиры; соответствие и лицензирование описаны в [SOURCE-REFERENCES.md](SOURCE-REFERENCES.md). Код проектов в этой коллекции написан заново; это не прямое копирование примеров или их ассетов.

## Текущие границы

Первая подборка проверяет основные workflows сцен, Prefab, ввода, Tween, Arcade Physics и Scene Manager. Она **не утверждает** полную поддержку Tilemap Editor, импортёров всех форматов Asset Pack, Animation Editor, Spine, Box2D, продвинутых FX/Shader и платформенных SDK. Эти направления следует добавлять отдельными примерами после проверки реальной интеграции в Codogma.
